A program that draws one invented passport spread for the Republic of Vulkara, a volcanic island nation in the Ember Isles: a data page with a procedural portrait and a machine-readable zone with correct check digits, and a visa page with entry and exit stamps from neighbouring Caldoria and the Isle of Merrow, plus a volcano-zone permit that reveals what kind of place Vulkara is. Pure Python 3.13 stdlib, deterministic, no network. Run it and it writes `/output/entry.png`.

## Run it

```sh
python3 main.py
```
